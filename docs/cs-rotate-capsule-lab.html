What the runtime cannot do


    
  
  • One hotkey button per band; a second digit typed a literal into the composer when measured.
    • 
  
  • No progress-bar or icon element; a meter is Text glyphs, so it costs width.
    • 
  
  • Rounded caps are Powerline glyphs (U+E0B6/E0B4): they need the caps font, the same consent the bar asks for.
    • 
  
  • A fill on the wrong theme looks wrong; the mod reading CS_TERM_THEME through env.get is not measured yet.
    • 
  
  • Hover restyles without a hook run, but only inside a keyed Box or a scope; it is polish, never state.
