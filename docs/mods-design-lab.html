Where a mod draws RenderComponent, RenderPropsOf

Source: ~/.claude/plugins/marketplaces/claude-code-plugins/mods/types/claude-code.d.ts (10.8k lines) and the 2.1.273 binary for border glyphs and the palette. A hook on ui.render matches one component. Two sites take a tree of the mod's own (AbovePrompt, Pane); the others draw the engine's component from props the hook may rewrite. Only the band honours hotkeys.

Box BoxProps, BoxHoverProps


    
    
      
  • flexGrow, flexShrink, alignSelf, columnGap/rowGap, minWidth/minHeight and the per-side margins and paddings exist too; they follow CSS flexbox and the lab draws the aggregate knobs.
    • 
      
  • hover restyles without a hook run: never a layout change. Refused on a Box that is not keyed unless it names a scope. A scope lights every element the same plugin drew with that string, in any site.
    • 
      
  • Reveal on hover: a child Box display="none" with hover={{display:"flex"}} inside a visible keyed Box. A scoped hover never reveals.
    • 
      
  • Colors are a theme key (see Palette) or a raw color (rgb(…), #rrggbb).
    •

  • Seven wrap spellings. end/truncate/truncate-end cut at the edge, truncate-start keeps the tail, middle/truncate-middle keep both ends; the lab draws them as the names read.

Button ButtonProps



  

    
    
    
    
    

      
      
      
    

    
    
    
    
  

  

    

    

    
    
      
  • hotkey: one digit or one lowercase letter, honoured only in the AbovePrompt band; anywhere else it is refused. A digit presses from an empty composer; a digit or letter presses while a band Button has the focus. Two Buttons on one hotkey: the later wins.
    • 
      
  • plain draws 1: label in the accent color, as a survey row; without plain, the surface's own button chrome ([ label ] in the terminal). A one-glyph plain label is a control by itself.
    • 
      
  • action names an engine keybinding whose chord presses the button from the prompt; unknown names are refused. A pane's over the band's over another's, then the last drawn.
    • 
      
  • autoFocus: the site's focus ring starts here when the site takes the keyboard; the first drawn of several wins. Under the pointer the button inverts regardless of hover.
    • 
      
  • onPress runs in the plugin's environment; the host holds a handle for the drawing's life. It cannot run a command inside a hook the turn waits on: schedule with $.clock.after(0, …).
    • 
    

  










Input InputProps



  

    
    
    
    
    
    
    
    
  

  

    

    

    
    
      
  • Enter runs onSubmit(value, e), the bottom of a ui.input chain of kind submit; no model turn unless the handler asks one. onInput fires on every change (kind change).
    • 
      
  • Terminal, desktop and VS Code have Input; the mobile surface has none yet.
    • 
      
  • Focused through the same ring as Button (abovePrompt:focus): click, or ctrl+x tab in the band.
    • 
    

  










Select SelectProps, SelectOption



  

    
    
    
    
    
    
  

  

    

    

    
    
      
  • At least one option, values unique. A pick runs onSelect(value, e), the bottom of a ui.select chain; the person's pick replaces value until the hook draws another.
    • 
    

  










Link LinkProps



  

    
    
  

  

    

    

    
    
      
  • https: only (or http://localhost), at most 2048 printable ASCII characters, spelled as new URL(href).href; no user@host, raw @, space or non-ASCII. A bad href refuses the whole tree the Link is in.
    • 
      
  • The terminal draws an OSC 8 hyperlink: the label underlined, the URL on hover in terminals that support it.
    • 
    

  










Code CodeProps



  

    
    
    
    
    
    
  

  

    

    

    
    
      
  • At most 10000 characters; tab and newline are the only control characters allowed. Nothing touches the disk: path only names the language.
    • 
      
  • format: 'diff' reads unified hunks (@@ -a,b +c,d @@ then  , +, - lines); a leading ---/+++ pair is read past. A source that does not parse as hunks is refused. startLine is ignored, hunks carry their numbers.
    • 
      
  • Only two wrap spellings here; Text's others are refused because the gutter leaves them no sense.
    • 
    

  










Raster RasterProps, $.ui.blit



  

    
    
    
    
    
    
    
    
  

  

    

    

    
encoded cells (what the JSX carries)

    
    
      
  • Every cell is a little-endian u32 triplet [codePoint, foreground, background], row-major, padded base64 of columns × rows triplets. A code point must be one printable width-1 BMP character (blocks, box drawing, braille are fine); a color is 0x00RRGGBB, or 0x01000000 for the terminal's default. A bad cell refuses the tree naming its index.
    • 
      
  • $.ui.blit({requestId, key, cells}) repaints a mounted Raster of this plugin's without a redraw, at the surface's frame rate: blits between frames fold into one. The size must be the mounted one; a resize is a redraw.
    • 
      
  • Terminal only. The desktop and mobile tables have Svg instead (source up to 131072 chars, required alt, optional sandboxed interactivity).
    • 
    

  










Client ClientProps, ClientElements



  

    
    
    
    
    
    
  

  

    

    

    
    
      
  • A Client hosts a surface module: a component that runs on the drawing thread under a time budget, keeps local state and timers across the plugin's redraws while a Client under this key stays in the tree, and draws from surface.elements (the terminal table minus Client and Raster). It receives key events through surface.onKey (Escape never arrives: it returns the focus) and posts back through ui.message.
    • 
      
  • module must be a string literal relative to the hooks file; a variable, a path outside the plugin or a missing file is refused at load. props is plain JSON, bounded like a tree's text, never closures.
    • 
      
  • A throw or an overrun unmounts the instance and draws one line naming the plugin and the module in its place.
    •

Rules the contract enforces



  

    
Redraw and time

    
    
      
  • ui.render runs once per input value (props, viewport width), plugin load, or $.ui.invalidate("ui.render"). A height change alone redraws nothing.
    • 
      
  • $.ui.invalidate: at most ten a second, thirty for the shown pane and the band; calls sooner fold.
    • 
      
  • $.ui.blit: frame rate, Raster only, size fixed to the mount.
    • 
      
  • $.clock.every(ms, fn) and $.clock.after(ms, fn) are the only timers; a hook the turn waits on cannot run a command, a 0 ms timer scheduled inside it can.
    • 
      
  • $.ui.toast(text, {timeoutMs}): the notification line under the prompt, 4000 ms by default. $.ui.log(text): one dim transcript line, not sent to the model.
    • 
    

    
Focus and keys

    
    
      
  • Focus sites: Pane and AbovePrompt (UiFocusComponent). The person focuses the band with a click or ctrl+x tab, collapses it with ctrl+x ctrl+a; Escape hands the keys back.
    • 
      
  • autoFocus on Button, Input, Select: first drawn wins, raises ui.focus with origin this plugin; a ring the person moved stays put.
    • 
      
  • Scroll sites: the same two. A band tree taller than maxRows scrolls in a window one row shorter over a dim n more row, and a bare digit then arms none of its hotkeys.
    • 
    

  

  

    
Panes

    
    
      
  • $.ui.open({id, title, focus, closeOnEscape, holdToasts, rows}): id 1-64 of letters, digits, _ and -; one pane per id, a second open retitles. focus is a request granted only over an empty composer. rows is a request too; a size the person set wins; default a third.
    • 
      
  • Placement: docked beside the transcript in fullscreen from 110 columns, else inline above the prompt. The person closes with ctrl+x x or the engine's mark (ui.close, origin person, which a hook may refuse); unload cannot be refused.
    • 
    

    
Surfaces

    
    
      
  • terminal: Box, Text, Button, Input, Select, Link, Code, Client, Raster.
    • 
      
  • desktop, vscode: the same minus Raster, plus Svg. Native buttons.
    • 
      
  • mobile: Box, Text, Button, Svg, Link, Code. No Input or Select yet (the control protocol carries presses only).
    • 
      
  • $.ui.resolve(e) returns the frozen element table for e.surface; a tree that names an element the surface lacks is refused.
    •
